## 1. `[MD]` Исторический контекст

> 2019 год. Мне 17. Школьный проект. Идея: компьютер распознаёт эмоции по лицу.

- **Стек:** Haar Cascade (OpenCV) → dlib HOG (детектор лиц) → dlib 68 landmarks → dlib ResNet 128d (эмбеддинг лица) → sklearn SVM (poly kernel) → 7 эмоций
- **Данные:** приватные — я и друзья, несколько сотен кадров на эмоцию
- **Accuracy:** ~45% (честно, на своих данных)
- **Почему это важно:** здесь родился **геометрический подход** — 68 точек лица как признаки для эмоций. Этот же подход (но с 468 точками MediaPipe) дожил до NB1.

## 2. `[MD]` Чему научил EmoZid (ключевые уроки)

| Урок | Как повлиял на MVM |
|------|-------------------|
| **HOG слишком медленный** для real-time | Переход на SCRFD → YuNet (1.6ms CPU) |
| **dlib 128d эмбеддинг оптимизирован под identity**, не эмоцию | NB4 докажет это эмпирически. Замена на SFace + отдельный emotion-классификатор |
| **SVM на 68 точках — слабый сигнал** | 68 → 468 точек (MediaPipe), потом → CNN (NB1) |
| **Свои данные — мало и несбалансированно** | FER2013, AffectNet, COCO как публичная база. Свои данные → оверсемплинг 15% |
| **45% accuracy — не провал, а baseline** | Каждое следующее решение сравнивается с предыдущим: 45% → 68% → 73% → 72% (легче) |

## 3. `[MD]` Публичная реконструкция

Оригинальный EmoZid использовал приватные лица. Здесь мы **реконструируем подход на публичных данных**:

- **Датасет:** CK+ (Cohn-Kanade) — публичный, 7 эмоций, 593 последовательности
- **Стек тот же:** dlib HOG → 68 landmarks → dlib ResNet 128d → SVM
- **Метрики:** accuracy, confusion matrix
- **Цель:** показать, что подход работает (и почему он ограничен) — без раскрытия приватных данных
