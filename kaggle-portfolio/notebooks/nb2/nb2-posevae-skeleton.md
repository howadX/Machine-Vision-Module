## Production Status (июль 2026)

**В production — OOD-gate.** VAE используется как **plausibility detector** для метода-C: `−log p(z)` > порог → поза помечается как «аномальная / вне распределения». Классификацию позы VAE НЕ делает — это передано методу-C (14 фич + RF → ≈0.93).

Модель: `pose_vae_public.bin` (переобучена на публичных данных URFD+Zenodo, seeded для воспроизводимости).
Порог перекалиброван: старый 14.3 (от самозаснятого VAE) → **170** (публичный VAE) — старый порог глушил ВСЮ позу в live-прогоне.

**Связанные крейты:** `mvm-posture` (VAE→OOD-gate, GRIP→classifier)

## 1. `[MD]` TL;DR

> Учим многообразие человеческих поз (β-VAE) и переиспользуем один латент для трёх задач:
> классификации, few-shot добавления классов и anomaly detection.

- β-VAE: 99→32 latent, 48.6K параметров, публичные данные (COCO + URFD + Zenodo)
- **Голова 1 — linear probe:** классификатор на latent, ~97% на раннем датасете / ниже на COCO
- **Голова 2 — few-shot:** новый класс из 5 примеров → прототипная классификация (без обучения)
- **Голова 3 — anomaly:** `−log p(z)` — выход за многообразие = «удивление» модели

## 2. `[MD]` Исторический контекст: зачем VAE, если будет GRIP?

VAE появился **раньше** GRIP. Хронология:

```
2024-03: PoseVAE обучен на своих данных (poses_dataset.csv)
         → классификатор на latent дал ~85% (несбалансированно)
2024-06: VAE переобучен на COCO (через weak supervision NB3)
         → на публичных данных качество ниже
2025-01: GRIP (14 фич + RF) → ≈0.93
         → VAE понижен до OOD-only
2025-06: Публичный VAE (URFD+Zenodo, seeded)
         → порог перекалиброван 14.3→170
```

**Почему VAE не выброшен:** он решает задачу, которую GRIP не решает — «похожа ли эта поза на те, что мы видели при обучении?» GRIP **всегда** выдаст standing/sitting/lying, даже для позы йоги или падения. VAE скажет: «не знаю, это вне моего опыта».

## 14. `[MD]` Честные метрики (важно для production)

В скелете заявлено «97% на 6 классах через linear probe». Это требует проверки:

- **Ранний датасет (свои позы):** ~85-97% (сильно несбалансирован, один человек)
- **COCO (публичный):** ожидаемо ниже — классы сложнее, вариативность поз выше
- **URFD + Zenodo (публичный):** метрика зависит от качества weak-меток (см. NB3)

В ноутбуке — **измерить на публичных данных и честно указать оба числа**.

## 15. `[MD]` Production Status (актуальное)

VAE в production — только OOD-gate. Причины:

| Причина | Детали |
|---------|--------|
| **Accuracy ниже GRIP** | ≈0.93 (GRIP) vs ~0.85 (VAE latent→classifier на публичных) |
| **Неинтерпретируем** | Латентные переменные ≠ физические признаки |
| **Зависимость от данных** | VAE нужно переобучать при добавлении новых поз; GRIP — нет |
| **Но:** ловит аномалии | Падение, йога, нестандартная поза → `−log p(z)` высокий → OOD |
