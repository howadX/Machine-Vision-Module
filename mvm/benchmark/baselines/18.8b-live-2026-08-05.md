Camera profile: `/dev/video0`, 1280×720 MJPG

This report records one bounded live-camera validation. It proves that the
Scene/Depth permit path executes in the production AgentMesh and that
Human/Fusion/Cortex remain live. It is not the controlled A/B throughput result
required by phase 18.8b.1.

## Procedure

The existing Hermes `mvm serve --mcp --with-camera` producer was stopped so the
current release binary could acquire `/dev/video0`. The checked-out code was
built in release mode and run with:

```bash
/usr/bin/time -f 'wall_seconds=%e' \
  target/release/mvm run \
  --max-frames 300 \
  --interval-ms 250 \
  --no-vision-log
```

`--no-vision-log` prevented this diagnostic run from adding a competing durable
session. `current_state.md` remained the read-only snapshot artifact.

observed 130 Scene and 11 Depth ticks therefore indicate approximately 30 Scene

agent health counters; phase 18.8b.1 must add direct extra-run and request
latency counters before treating them as scheduler metrics.

Confirmed live:

- Scene and Depth execute beyond their fixed cadence through bounded runtime
  control;
- Human, Fusion and Cortex continue publishing without agent errors;

- request wait and resolution latency;

Scheduling Spike. The 30 inferred extra Scene runs are specifically a signal to
