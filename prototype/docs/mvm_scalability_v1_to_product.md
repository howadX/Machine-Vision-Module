## 0. Точка А: pipeline v1 — что мы имеем

```
Камера (Logitech C270, 640×480)
    │
    ▼
dlib HOG (детекция лица, 30-80ms CPU)
    │
    ▼
dlib 68 landmarks (2D-точки лица)
    │
    ├── dlib ResNet 128d (эмбеддинг, 10-15ms)
    │     └── Euclidean distance → Face ID (Вадим, Даня, Никита, Белла)
    │
    └── sklearn SVM (poly kernel, C=2.0, gamma=2.0)
          на 128d эмбеддингах → 7 эмоций (~45% accuracy)
```

### Что здесь ЦЕННО (авторский вклад)

| Компонент | Что сделано СВОИМИ руками |
|-----------|--------------------------|
| `1_make_dataset.py` | Свой сборщик лиц через Haar Cascade → датасет эмоций |
| `2_extract_descriptors.py` | Свой экстрактор: 68 точек → 68 расстояний от носа → 128d эмбеддинги |
| `3_train_svm.py` | Свой классификатор: полиномиальный SVM с ручным подбором C=2.0, gamma=2.0 |
| `4_identification.py` | Свой рантайм: цикл детекции → идентификации → эмоции → audio feedback |
| Данные | **Свои лица** (4 человека, 7 эмоций каждый) — не FER2013, не AffectNet |

### Что здесь ОГРАНИЧИВАЕТ (инструменты, не код)

| Проблема | Причина |
|----------|---------|
| dlib HOG не детектит лица < 80px | Инструмент 2005 года, не наш код |
| dlib ResNet 128d оптимизирован под identity, а не эмоции | Архитектурный конфликт: identity vs expression |
| SVM на identity-эмбеддингах — принципиально слабый сигнал | Identity-эмбеддинг ПОДАВЛЯЕТ эмоции |
| 68 точек — 2D, нет устойчивости к поворотам | dlib shape predictor обучен на iBUG 300-W (фронтальные лица) |

## 1. Философия масштабирования: свой продукт vs готовая коробка

### Что значит «свой продукт» для MVM

```
ЧУЖОЕ (берём как инструмент):
  - Библиотеки: InsightFace, MediaPipe, LightGBM, ONNX Runtime
  - Предобученные веса: SCRFD, ArcFace, MediaPipe FaceMesh
  - Фреймворки: scikit-learn, PyTorch

СВОЁ (делаем сами):
  - Пайплайн: последовательность шагов, логика рантайма
  - Данные: свои лица, свои эмоции, свои сцены
  - Обучение: свои гиперпараметры, своя предобработка, свой fine-tuning
  - Интеграция: как компоненты связаны друг с другом
  - Пороги, метрики, оверлей, audio feedback — ВСЁ авторское
```

### Принцип «не заменять, а расширять»

```
v1 (легаси)          →  v2 (миграция инструментов)  →  v3 (тело)  →  v4 (сцена)
────────────────────────────────────────────────────────────────────────────
dlib HOG             →  SCRFD (InsightFace)           остаётся      остаётся
68 landmarks         →  478 MediaPipe FaceMesh        остаётся      остаётся
ResNet 128d          →  ArcFace 512d                  остаётся      остаётся
SVM poly             →  LightGBM (геометрия лица)     расширяется   расширяется
                        + LightGBM (геометрия тела)   + ST-GCN      + контекст
```

Каждый новый слой НЕ заменяет старый, а добавляет данные к классификатору.

**Ключевое:** поменялись ИНСТРУМЕНТЫ, но АРХИТЕКТУРА и ЛОГИКА — авторские.

### Свой датасет — главный актив

```
data/my_emotions/
├── angry/      # 50-100 кадров → СВОИ лица, СВОЯ камера
├── disgust/
├── fear/
├── happy/
├── sad/

└── neutral/
```

Не FER2013 (чужое, 48×48, серые), не AffectNet (чужое, веб-фотки). **Свои данные — domain shift = 0.**

### Где сейчас потолок и почему

```
LightGBM на 478 геометрических признаках: 48.5% accuracy
```

**Почему 48.5%, а не 70%:**
- Геометрические признаки (расстояния от носа) игнорируют текстуру — морщины, напряжение губ, форма бровей
- Нет temporal контекста — эмоция на одном кадре, без предыдущих
- Только лицо — нет позы тела, нет контекста сцены

**Вывод:** чтобы поднять accuracy, не нужно менять классификатор. Нужно добавить НОВЫЕ ПРИЗНАКИ поверх существующих.

## 3. Генерация 3: тело (Body Pipeline) — СВОЙ модуль

### Что делаем

Добавляем **второй набор признаков** — геометрию тела — и обучаем LightGBM на объединённом векторе.

### Архитектура: два параллельных экстрактора

```python
# Сейчас (v2): только лицо
def extract_features(image):
    face_landmarks = mediapipe_face(image)       # 478 точек
    face_features = distances_from_nose(face)     # 478 чисел
    return face_features                          # shape: (478,)

# Будет (v3): лицо + тело
def extract_features(image):
    face_landmarks = mediapipe_face(image)        # 478 точек (уже есть)
    body_landmarks = mediapipe_pose(image)        # 33 точки (НОВОЕ)

    face_features = distances_from_nose(face)     # 478 чисел (уже есть)
    body_features = distances_from_hip(body)      # 33 числа (НОВОЕ)
    body_features += angles_between_joints(body)  # 18 углов (НОВОЕ)
    body_features += asymmetry_index(body)        # 1 число (НОВОЕ)

    return np.concat([face_features, body_features])  # shape: (530,)
```

### Что даёт геометрия тела для эмоций

| Признак тела | Как связан с эмоцией |
|-------------|---------------------|
| Угол наклона головы (шейный отдел) | Грусть → голова опущена. Гордость/радость → поднята |
| Положение плеч (подняты/опущены) | Страх → плечи подняты. Расслабленность → опущены |
| Расстояние между запястьями | Скрещенные руки → защитная поза (дискомфорт) |
| Асимметрия тела | Сильные эмоции → асимметричная поза |
| Скорость движения (temporal) | Радость → быстрые движения. Грусть → медленные |

### Свой датасет тела

```bash
# Расширяем my_emotions:
data/my_emotions/
├── angry/
│   ├── face_001.jpg    # уже есть (лицо)
│   ├── body_001.jpg    # НОВОЕ — полный рост, та же эмоция
│   └── ...
```

**Важно:** не нужен готовый датасет (MPII, COCO). Нужны СВОИ фотографии полного роста с семью эмоциями. 20-30 кадров на эмоцию = 200 кадров всего.

### Временной контекст: ST-GCN на своих данных

```python
# src/pipeline/4_temporal_emotion.py
# Вход: последовательность из 30 кадров (1 секунда)
# Для каждого кадра: face_features + body_features
# ST-GCN учится на последовательностях
# Выход: эмоция с учётом динамики
```

**Почему это СВОЙ модуль, а не готовое решение:**
- ST-GCN — это архитектура (инструмент)
- Данные для обучения — СВОИ последовательности эмоций (30 кадров × 7 эмоций × 4 человека)
- Классы — СВОИ (7 эмоций, а не 60 классов NTU)

### Ожидаемый прирост

```
v2 (только лицо, статика):     48.5%
v3 (+ тело, статика):          55-58%   (+7-10%)
v3 (+ тело + temporal):        60-63%   (+12-15%)
```

## 6. Свой подход vs готовая коробка — итоговая таблица

| Компонент | Готовая коробка | Свой продукт (MVM) |
|-----------|----------------|---------------------|
| **Детектор лиц** | YOLOv10m (COCO 80 классов) | SCRFD (только лица, быстрее) |
| **Детектор объектов** | YOLOv10m (чужие классы) | YOLOv10m → fine-tune на СВОИХ 10-15 классах |
| **Эмбеддинг лиц** | ArcFace (предобучен) | ArcFace + СВОИ эталоны (4 человека) |
| **Landmarks** | MediaPipe FaceMesh (предобучен) | MediaPipe + СВОЙ экстрактор геометрических признаков |
| **Эмоции (лицо)** | HSEmotion (ВШЭ, чужие данные) | LightGBM на СВОЕЙ геометрии лица |
| **Поза тела** | MediaPipe Pose (предобучен) | MediaPipe + СВОЙ экстрактор признаков тела |
| **Действия** | VideoMAE (Kinetics, 400 классов) | ST-GCN на СВОИХ последовательностях |
| **Классификатор** | sklearn SVM (библиотека) | LightGBM + СВОИ гиперпараметры (n_est, lr, max_depth) |
| **Трекер** | BoxMOT (MOT17/20) | Свой Kalman + IoU трекер (200 строк) |
| **Глубина** | Depth Anything V2 (предобучен) | Depth Anything + СВОЯ калибровка под камеру |
| **VLM** | Qwen2-VL (предобучен) | Qwen2-VL + СВОЙ промпт + СВОЙ контекст |
| **Данные** | AffectNet, FER2013, COCO | `my_emotions/`, `my_objects/` |
| **Пайплайн** | DeepStream/Savant | СВОЙ Python-пайплайн (src/pipeline/) |

**Правило:** модель может быть чужой (предобученной). Данные, обучение, пороги, интеграция — ТОЛЬКО свои.
