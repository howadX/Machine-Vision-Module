# Full-Body Human Datasets — каталог

**Цель:** найти датасеты с людьми в полный рост для расширения Модели Б.

---

## 1. COCO-WholeBody (133 keypoints) 🥇

**Лучший вариант.** Расширение COCO: 17 body + 6 feet + 68 face + 42 hands = 133 точки. Полный рост, стопы, пальцы.

| Параметр | Значение |
|----------|----------|
| Изображений | 118K (те же что COCO) |
| Экземпляров | ~250K |
| Точек | 133 (full-body!) |
| Скачивание | http://images.cocodataset.org/zips/train2017.zip + аннотации |
| Лицензия | CC BY 4.0 |

**Для MVM:** стопы (6 точек) — критичны для lying vs standing. Уже есть val2017 локально!

---

## 2. LSP / Leeds Sports Pose 🥈

**Спортивные позы — много lying!** Теннис, бадминтон, лёгкая атлетика, бейсбол.

| Параметр | Значение |
|----------|----------|
| Изображений | 2,000 |
| Экземпляров | 2,000 |
| Точек | 14 (COCO-like) |
| Скачивание | https://sam.johnson.io/research/lsp_dataset.zip (MIRROR) |
| Лицензия | Исследовательская |

**Для MVM:** спортсмены в динамике — много lying (нырок, падение, подкат). Прямая ссылка.

---

## 3. CrowdPose

**Multi-person в толпе.** 20K изображений, 80K экземпляров. 14 точек.

| Параметр | Значение |
|----------|----------|
| Изображений | 20,000 |
| Экземпляров | 80K |
| Точек | 14 |
| Скачивание | https://github.com/Jeff-sjtu/CrowdPose |
| Лицензия | Исследовательская |

**Для MVM:** толпа → много перекрытий → lying на земле.

---

## 4. OCHuman

**Окклюдированные люди.** 4,731 изображений, 8,110 экземпляров. COCO-формат.

| Параметр | Значение |
|----------|----------|
| Изображений | 4,731 |
| Точек | 17 (COCO) |
| Скачивание | https://github.com/liruilong940607/OCHumanApi |
| Лицензия | Исследовательская |

**Для MVM:** люди за объектами → частичная видимость → сложные позы.

---

## 5. Halpe-FullBody (26 keypoints)

**136 точек на всё тело.** Расширение COCO: 26 body (включая стопы, пальцы) + лицо + руки.

| Параметр | Значение |
|----------|----------|
| Изображений | ~40K (COCO-based) |
| Точек | 136 |
| Скачивание | https://github.com/Fang-Haoshu/Halpe-FullBody |
| Лицензия | CC BY-NC |

**Для MVM:** стопы, пальцы ног — критичны для lying.

---

## 6. Penn Action

**Спортивные действия + ключевые точки.** 2,326 видео, 15 классов действий, 13 точек.

|----------|----------|

| Точек | 13 |
| Скачивание | http://dreamdance.org/penn-action/ |
