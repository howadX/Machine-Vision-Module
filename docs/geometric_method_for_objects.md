# Геометрический метод для предметов: ресерч

**Вопрос:** можно ли применить геометрический подход (расстояния от референсной точки) к классификации предметов?

**Краткий ответ:** нет в текущем виде, но существуют родственные геометрические методы.

---

## 1. Почему геометрия лица работает, а предметов — нет

### Что делает геометрию лица такой эффективной

```
Лицо — rigid + deformable объект с АНАТОМИЧЕСКИМИ КОНСТАНТАМИ:
  - Межзрачковое расстояние ~63mm (const для всех людей)
  - Кончик носа — стабильная референсная точка
  - 468 landmarks предопределены и ВСЕГДА в одних и тех же местах
  - Эмоции меняют ОТНОСИТЕЛЬНЫЕ расстояния (рот, брови), а не абсолютные
```

**Ключевое:** MediaPipe даёт 468 landmarks для ЛЮБОГО лица. Они семантически идентичны: landmark №4 — всегда кончик носа, №33 — всегда левый глаз.

### Почему предметы — другая история

```
Чашка:
  - Нет анатомических констант (ручка может быть слева, справа, отсутствовать)
  - Разные чашки имеют РАЗНУЮ геометрию (высокая кружка vs широкая пиала)
  - Ракурс радикально меняет контур (сверху — круг, сбоку — трапеция)
  - Нет MediaPipe для чашек — никто не разметил 468 landmarks на 100K чашек

Стул:
  - 4 ножки vs 1 ножка vs офисное кресло — геометрия несопоставима
  - Вид сбоку vs вид спереди — количество видимых landmarks меняется
```

**Вывод:** геометрический подход требует:
1. Фиксированного набора landmarks → для предметов не существует
2. Семантической идентичности landmarks → landmark №5 на чашке А ≠ landmark №5 на чашке Б
3. Стабильной референсной точки → центр масс чашки зависит от ракурса

## 2. Родственные геометрические методы для предметов

### Hu Moments (инварианты формы)

```
Семь чисел, инвариантных к повороту, масштабу и сдвигу.
Вычисляются из контура объекта.

Работает для: различения простых форм (чашка vs книга vs мяч)
Не работает для: тонких различий (кружка vs пиала)
```

**Пример кода:**
```python
import cv2
contour, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
moments = cv2.HuMoments(cv2.moments(contour[0])).flatten()
# 7 чисел → можно подать в LightGBM!
```

**Оценка точности:** 60-70% для 10-15 классов бытовых предметов (в идеальных условиях)

### Fourier Descriptors (спектр контура)

```
Контур → полярные координаты (r, θ) → FFT → low-frequency коэффициенты
Инвариантны к повороту и начальной точке.

Работает для: объектов с характерным контуром (бутылка, чашка, стул)
```

**Пример:**
```python
contour_complex = contour[:, 0, 0] + 1j * contour[:, 0, 1]
fourier = np.fft.fft(contour_complex)
descriptors = np.abs(fourier[:20])  # первые 20 гармоник
# 20 чисел → LightGBM
```

**Оценка:** 55-65% на бытовых предметах

### Shape Context (Belongie et al., 2002)

```
Для каждой точки контура: гистограмма относительных позиций всех остальных точек.
Логарифмическая полярная сетка.

Работает для: matching форм (эта чашка похожа на ту чашку?)
Не работает для: классификации (дорого!)
```

**Проблема:** O(N²) для N точек контура, не для real-time.

### SIFT/SURF Keypoints + Geometric Verification

```
SIFT детектит keypoints → SURF описывает → matching с эталоном
Геометрическая верификация: RANSAC аффинное преобразование

Работает для: specific object recognition («эта конкретная кружка Вадима»)
Не работает для: general classification («какая-то кружка»)
```

### Keypoint Detection для объектов (аналог MediaPipe, но для предметов)

```
Модели: 
  - ViTPose/RTMPose (если обучить на keypoints предметов)
  - SuperPoint (self-supervised keypoints, Magic Leap)
  - SiLK (Google, 2023) — learning keypoints без разметки

Проблема: НЕТ датасета с keypoints для бытовых предметов.
Нужно разметить вручную: 100 чашек × 20 keypoints = 2000 точек.
```

## 3. Экспериментальная оценка

### Что можно проверить прямо сейчас

```python
# Берём YOLOv8-seg → получаем маску объекта → извлекаем контур → Hu Moments
# Плюс: bounding box aspect ratio, площадь, цветовые гистограммы

def extract_object_features(mask, bbox):
    # 1. Геометрические (контур)
    contour = get_largest_contour(mask)
    hu = cv2.HuMoments(cv2.moments(contour)).flatten()      # 7
    area = cv2.contourArea(contour)
    perimeter = cv2.arcLength(contour, True)
    circularity = 4 * np.pi * area / (perimeter ** 2)        # 1
    aspect_ratio = (bbox[2]-bbox[0]) / (bbox[3]-bbox[1])    # 1
    
    # 2. Цветовые (гистограмма)
    hsv = cv2.cvtColor(crop, cv2.COLOR_BGR2HSV)
    h_hist = cv2.calcHist([hsv], [0], None, [8], [0, 180])  # 8
    
    return np.concat([hu, [circularity, aspect_ratio], h_hist.flatten()])
    # Итого: 7 + 2 + 8 = 17 признаков → LightGBM
```

**Ожидаемая точность:** 50-65% для 10-15 классов (хуже YOLO, но интерпретируемо и СВОЁ)

## 4. Вывод

**Геометрический метод в чистом виде (landmarks → расстояния) — НЕТ для предметов.**

Причина: нет универсальных landmarks для предметов. У лица они даны анатомией. У чашки их нет.

**НО:** геометрический ПОДХОД (контур → Hu Moments / Fourier → LightGBM) — ДА, возможен.

```
Лицо:     MediaPipe 468 → расстояния → LightGBM  → 48.5%
Предметы: YOLO-маска → Hu Moments + цвет → LightGBM → 50-65% (оценка)
```

**Практическая рекомендация для MVM:**

1. **Предметы:** YOLOv10m, fine-tune на своих 10-15 классах → 85-95% точность. Это не «чужая готовая коробка» — данные и обучение СВОИ
2. **Геометрический подход:** оставить для лица (где он силён) + добавить тело
3. **Контурные признаки:** использовать как ДОПОЛНИТЕЛЬНЫЙ источник сигнала (не основной)
